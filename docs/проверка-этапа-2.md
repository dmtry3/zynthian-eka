# Проверка этапа 2 на Zynthian V5: парты и Lock

Обновить на Pi:

```bash
cd zynthian-audio-looper && git pull && ./scripts/install.sh && systemctl restart zynthian
```

Педали: 8 — Lock, 10 — следующий парт (удержание — предыдущий). Контроллеры Lock, Next Part,
Prev Part на страницах Track и Navigate. Точки партов слева: пустой — контур, записанный — серая
заливка, текущий — зелёный в квадрате, ожидающий — мигает. Пока переход ждёт, внизу «PART 1 → 2».

## Переход в пустой парт

1. Парт 1: записать ритм на дорожку 1 и бас на дорожку 2. У дорожки 1 Lock уже стоит по умолчанию
   (замок у номера); педаль Lock снимает и ставит его.
2. Тап «Следующий парт»: точка парта 2 мигает, переход в конце цикла самого длинного лупа
   (настройка PART AT, по умолчанию LOOP END; можно BAR, BEAT, NOW).
3. В парте 2 ритм играет дальше без скачка и щелчка, бас плавно затихает.
   Активной стала дорожка 2 (первая свободная) — можно сразу жать запись.
4. Записать аккорды. Овердаб на ритме в парте 2 не меняет ритм в парте 1.

## Переход в записанный парт

1. Удержание «Следующий парт»: назад в парт 1 в конце цикла. Его лупы начинают с начала цикла,
   ритм и бас — как были записаны (без овердабов парта 2).
2. Тап: снова парт 2.

## Мелочи

- Два тапа подряд до такта: цель на парт дальше (через парт). Удержание — назад. Вернулись на текущий — отмена.
- Текущий парт пустой: переход сразу.
- Идёт запись или овердаб в момент перехода: закрывается на границе.
- «Следующий парт», затем сразу Rec (до такта): внизу «REC → PART 2», запись начинается ровно
  на границе в новом парте на активной там дорожке; старый парт не трогается. Rec ещё раз — отмена.
- Lock на копии сохраняется: в следующий пустой парт дорожка пойдёт снова. Lock ещё раз — снять.
- Undo на копии снимает только овердабы, записанные в новом парте; основу копии не трогает.

## Приёмка этапа 2 (из ТЗ)

Смена парта на границе такта без разрыва, дорожки с Lock играют в новом парте без скачка фазы.
