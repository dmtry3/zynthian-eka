# Проверка этапа 7 на Zynthian V5: сетка 2×2 / 4×4 / 6×6

Обновить на Pi (плагин и виджет вместе: поменялся формат общей памяти волн):

```bash
cd zynthian-audio-looper && git pull && sudo ./scripts/install.sh && sudo systemctl restart zynthian
```

## Выбор сетки (шестерёнка → GRID)

1. Лупов нет: касание 2×2, 4×4 или 6×6 меняет сетку сразу.
2. Лупы есть: первое касание — кнопка мигает красным «CLEAR ALL?», внизу «TAP AGAIN TO CLEAR».
   Второе касание в течение 3 с меняет сетку: лупы плавно затихают и стираются, курсор на дорожке 1 парта 1.
   Через 3 с без второго касания ничего не происходит.
3. После смены сетки уровни, панорамы, режимы каналов и скорости дорожек — по умолчанию.
   Dry, Master и ограничитель остаются.
4. Сетка сохраняется в снапшоте Zynthian. Снапшот с другой сеткой загружается со своим микшером.

## 6×6

1. Экран Loop: 6 строк дорожек, 6 точек партов. Номера, скорость, волны читаются с двух метров?
2. «Следующая дорожка» идёт 1 → … → 6 → 1, удержание — назад. «Следующий парт» так же по 6 партам.
3. Lock: первая дорожка каждого парта по умолчанию с замком, в пустой парт переходит как раньше.
4. Mixer: 6 полос, фейдер, панорама, ST/L/R и M каждой дорожки работают, ручки страницы Mix — на активную.
5. Speed: касание по скорости 5-й и 6-й дорожки открывает Speed этой дорожки.
6. Настройки: TRACK LENGTH — 6 строк.

## 2×2

1. Loop: 2 высокие строки с крупными волнами, значки обычного размера. Mixer: 2 полосы.
2. Дорожки и парты ходят по кругу 1 → 2 → 1.

## Нагрузка (критерий этапа)

6 играющих дорожек в 6×6, скорость не 1× и следование темпу: не больше 15% одного ядра
(`top` или `htop`, процесс jalv), ни одного xrun за час игры.
