# Проверка этапа 1 на Zynthian V5

Обновить на Pi:

```bash
cd zynthian-audio-looper && git pull && ./scripts/install.sh && systemctl restart zynthian
```

Загрузка плагина теперь занимает около секунды: он сразу забирает пул памяти 2 ГБ.

Все кнопки ниже — педали футсвитча (MIDI learn на контроллеры страниц, режим momentary).

## Настройки (шестерёнка справа вверху)

Касание по шестерёнке открывает настройки, касание по правой нижней вкладке или шестерёнке закрывает.
Левая половина значения уменьшает, правая увеличивает. Изменённое значение горит зелёным.
Проверить: после перезагрузки снапшота настройки сохраняются.

## Free (MODE = FREE)

1. Rec: дорожка красная, идёт счёт секунд. Rec ещё раз: цикл закрылся, дорожка играет (активная — зелёная).
   На стыке цикла нет щелчка, начало не обрезано.
2. Rec: овердаб (оранжевый). Rec: играет. Повторить 10 раз.
3. Undo (тап): снимается последний овердаб, на слух по одному. Undo (удержание 0,5 с): Redo возвращает.
4. Undo во время овердаба: овердаб отменяется сразу.
5. Mute: плавно затихает за 200 мс (серый), ещё раз — плавно возвращается.
6. Reverse: разворот как у ленты за 50 мс (фиолетовый), без щелчка. Ещё раз — обратно.
   В Quantize такт доигрывается: лента останавливается ровно на тактовой черте, после разворота луп в долю.
   Повторное нажатие до черты отменяет разворот.
7. Next Trk (тап): следующая дорожка, удержание — предыдущая. Записать 2–3 дорожки разной длины.
8. Reset (тап): активная дорожка плавно очищается. Undo возвращает её.
9. Reset (удержание 1 с): всё очищается.

## Quantize (MODE = QUANTIZE, по умолчанию)

1. Транспорт Zynthian запущен. Rec посреди такта: дорожка мигает красным (ждёт такта), запись начинается с такта.
2. Rec посреди такта: запись идёт до конца такта, потом играет (в ROP — овердаб). Rec сразу после черты
   (не позже 200 мс): цикл закрывается на этой черте.
3. LENGTH 1 = 2 BARS: запись сама закрывается через 2 такта.
4. На полосе дорожки тонкие линии долей и толстые линии тактов.
5. MUTE AT = BAR: mute срабатывает на ближайшем такте.
6. Транспорт стоит, лупов нет: запись начинается сразу, такты считаются от неё.
7. Остановить транспорт: лупы плавно затихают (цвет приглушается). Запустить: входят обратно в долю
   с метрономом Zynthian. Повторить несколько раз в разные моменты.

## Play/Stop (страница Navigate, педаль 11 или кнопка V5 через MIDI learn)

1. Транспорт идёт. Play/Stop: лупы затихают на ближайшем такте (MUTE AT), метроном Zynthian идёт дальше.
2. Play/Stop ещё раз: лупы входят с начала такта, в долю.
3. Нажать дважды до черты: команда отменяется.
4. Остановили лупы педалью, потом остановили и запустили транспорт: лупы ждут педали Play/Stop.

## ROP (REC ORDER = ROP)

Rec, Rec: после закрытия цикла сразу идёт овердаб (оранжевый), хвост ноты ложится на начало.
Rec: играет. Undo снимает этот овердаб, основа остаётся.

## Приёмка этапа 1 (из ТЗ)

10 овердабов подряд на одной дорожке, undo возвращает звук по одному слою, mute и reverse без щелчков на слух.
