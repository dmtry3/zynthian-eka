# ТЗ: Eka Grain Flow — гранулярный эффект для живой игры (Zynthian)

Копия документа из проекта «Zynthian - создаю», версия 0.3 от 2026-11-13. Рабочее название **Eka Grain Flow**.

Решения этапа M0, принятые при написании кода, — в конце, в разделе «Заметки реализации».

## 1. Концепция

Гранулярный эффект в формате LV2 для Zynthian (Raspberry Pi 5), шестой плагин бандла **zynthian-eka**. Живой вход непрерывно пишется в кольцевой буфер, три потока зёрен читают из него и собирают новый звук. Образец по устройству и характеру — Autochroma (imagiro), упрощённая под четыре энкодера и сцену.

Берём только идеи и общеизвестную технику. Код, графику, пресеты и название Autochroma не используем.

## 2. Что есть в Autochroma и что мы с этим делаем

| В Autochroma | Решение | Почему |
|---|---|---|
| Буфер с зёрнами на экране | **Берём** | Главный экран виджета |
| Три потока вкладками 1 / 2 / 3 | **Берём** | Касание выбирает поток, ручки настраивают его |
| placement: offset, rate | **Берём** | Основа звука |
| lifetime: length, pitch, reverse | **Берём** | Основа звука |
| out: spread, gain | **Берём** | |
| out: фильтр с графиком | **Упрощаем** до одной ручки Filter | График на энкодерах не настроить |
| lifetime: shape | **Упрощаем**: выбор касанием на виджете, без ручки | Редко меняется в игре |
| freeze (кнопка) | **Берём и добавляем педаль** | Главный живой жест |
| Общие gain и mix | **Берём** | |
| scan: mode, speed | **Убираем**, остаётся только lock (чтение идёт за записью) | Свободное сканирование нужно для файлов |
| placement: grid, snap | **Убираем** (кандидат после v1) | Требует надёжного темпа от Zynthian |
| Загрузка аудиофайлов, буфер 30 с | **Убираем**, буфер до 8 с | Вход всегда живой |
| До 150 зёрен | **Снижаем** до 48 (уточнить замером) | CPU Raspberry Pi |
| Панель mod (4 модулятора) | **Открытый вопрос**, см. §9 | Нужен скриншот панели |

Добавляем то, чего на сцене не хватает: Freeze на педаль, сухой сигнал без задержки.

## 3. Звуковой путь

```
 IN L/R ──┬──────────────────────────────────► DRY ─────┐
          ▼                                              ▼
   ┌─────────────┐          ┌─ Поток 1 ─ Filter ─┐
   │ Кольцевой   │─ зёрна ─►├─ Поток 2 ─ Filter ─┼─► Σ ─► Gain ─► MIX ─► OUT L/R
   │ буфер       │          └─ Поток 3 ─ Filter ─┘
   └─────────────┘
      ▲ Freeze останавливает запись
```

- **Буфер**: стерео, длина 1…8 с (по умолчанию 4 с). Память выделяется только при запуске.
- **Freeze**: запись останавливается, зёрна продолжают играть захваченный звук. Без щелчков.
- **Сухой сигнал** идёт на выход без задержки.
- **Потоки**: три независимых генератора зёрен; по умолчанию включён только первый. Общий пул — до 48 зёрен.

## 4. Параметры

Четыре страницы ручек: одна общая и три для **выбранного** потока.

| Страница | Ручки |
|---|---|
| **Main** | Stream (1 / 2 / 3), Mix, Feedback, Freeze |
| **Grain** | Offset (мс позади записи), Rate (мс между зёрнами), Length (мс), Pitch (±24 полутона) |
| **Flow** | Scan (−200…+200 %, 0 — Off), Fine (±50 центов), Intervals, Spread % |
| **Out** | Reverse %, Filter (−100…+100, в центре выключен), Spray %, Level (дБ потока) |

Без ручек, касанием на виджете: включение потоков, Shape (мягкое / резкое окно), Buffer (1…8 с).
Freeze — на педаль через MIDI-learn Zynthian; Latch или Momentary задаёт сама педаль (переключатель шлёт 127 и 0
на каждое нажатие — Latch; кнопка шлёт 127 при нажатии и 0 при отпускании — Momentary).

## 5. Виджет

Один экран: буфер (профиль уровня входа, бегущий, стоит при Freeze), зёрна трёх цветов поверх него, вкладки
1 / 2 / 3 (касание выбирает поток, долгое касание включает и выключает), кнопка Freeze, счётчик зёрен.

## 6–10

Платформа, критерии приёмки, этапы, риски — как в ТЗ 0.3 в проекте. Этапы: M0 каркас и проверки на устройстве,
M1 полный гранулятор и вкладки, M2 Freeze с педалью, Filter, замер CPU, M3 пресеты, README, публикация.

## Заметки реализации

- **Колонка потоков и Init** (2026-11-15): кнопки 1–2–3 вытянуты вертикально
  слева, остаются видны на Mod. Касание выбирает поток, долгое включает / выключает.
  Колонка обновляется только при смене выбора, маски включения или размера экрана.
  Pitch по умолчанию и в Factory Init: +12, 0, −12; в Factory Init включён только второй поток.
- **LFO polarity и вертикальный Rate** (2026-11-15): на странице Mod каждый LFO переключается между биполярным
  −1…+1 и положительным 0…+1 режимами; Rate регулируется вертикальным перетаскиванием (вверх — быстрее).
- **Привязка Pitch** (2026-11-15): в Intervals добавлены индексы 9…13:
  Q Oct, Q Fifth, Q Major, Q Minor, Q Penta. Старые 0…8 не изменены. В Q-режимах
  Pitch вместе с модуляцией округляется к ступени при рождении зерна и фиксируется;
  Fine применяется после округления. Глубина 100 даёт ±24 полутона на источник,
  итог ограничен ±36. Запас до головки и длина зерна учитывают максимальную
  разрешённую ноту, а не неквантованный размах. Для старых режимов остаются ±2
  полутона и непрерывная модуляция. Добавлен пресет Stepped Sky; новых портов нет.

- **Страница Flow** (2026-11-15): порядок страниц Main → Grain → Flow → Out.
  Flow: Scan, Fine, Intervals, Spread. Все четыре работают с выбранным потоком;
  соответствующие кнопки убраны с виджета. Смена вкладки сохраняет открытую Flow.
  Четыре входных порта добавлены после прежних 12 контролов (всего 16), до аудиопортов;
  порядок страниц задают группы TTL. Символы прежних портов и URI State сохранены.
  Отдельные cur_scan / cur_fine / cur_interval / cur_spread сообщают виджету значения
  выбранного потока для перестановки ручек; устаревшие значения входов при смене потока
  или восстановлении State не перезаписывают сохранённые параметры.

- **Scan** (2026-11-15): `s1_scan` … `s3_scan`, −200…+200 %, добавлены в конец
  списка параметров, без изменения индексов портов. 0 — прежний режим Offset;
  ненулевое значение включает независимый курсор источника (±100 % = ±1 кадр
  источника на кадр выхода). Курсор обновляется по блокам, размещение — при рождении
  зерна; звучащие зёрна не меняют скорость из-за Scan. Offset сдвигает курсор,
  Spray и модуляция действуют вокруг него. Границы учитывают Pitch, Reverse,
  длину и 20-мс переход Freeze. При восстановлении State курсоры стартуют заново;
  в старых пресетах Scan выключен. Нет новых аудиобуферов и анимации.

- **Freeze Amount и отдельная кнопка** (2026-11-15): `freeze_amount` 0–100 %
  удерживает часть прошлого оборота Buffer со сглаженным стыком; 0 — живая запись,
  100 — остановленная головка. Старый бинарный порт `freeze` и MIDI-педаль остаются
  отдельной кнопкой полного захвата: она имеет приоритет, но не меняет Amount.
  После отпускания возвращается заданная степень удержания. Start / End / Refresh
  удалены; Amount меняется слайдом по кнопке, короткий тап переключает захват.
  Отдельного меню нет; надпись сокращена до Frz NN%. Новых выделений или копирования
  всего буфера в аудиопотоке нет. `freeze_phase` и `record_peak` остаются после
  существующих портов; аудиоданные буфера не сохраняются в State.

- **Выбор потока: вариант 2.** У плагина 12 «лицевых» ручек Grain/Flow/Out; значения трёх потоков — LV2-параметры
  `s1_offset` … `s3_level`, их хранит плагин. Поворот лицевой ручки пишется в выбранный поток и сообщается хосту
  (patch:Set). Смена потока ничего не копирует; виджет переставляет ручки на значения нового потока.
  После загрузки пресета выходной порт `loads` увеличивается, и виджет переставляет ручки снова.
- **Минимальный Offset.** Зерно вперёд при записи начинается не ближе `Length × (ratio − 1)` к головке записи,
  при Freeze — не ближе `Length × ratio` (головка стоит). Значение для выбранного потока — порт `min_offset`.
- **Freeze и одинаковые зёрна.** При заморозке все зёрна начинались бы с одного места, и копии одного кусочка
  через Rate гасили бы друг друга (гребёнка). Поэтому при Freeze с выключенным Scan каждое зерно начинается со случайного места
  в пределах одной длины зерна дальше Offset.
- **Громкость.** Перекрывающиеся зёрна одной высоты читают один и тот же задержанный сигнал и складываются в фазе;
  громкость зерна делится на сумму окон, поэтому Rate и Length почти не меняют уровень.
- **Filter.** −100: ФНЧ 200 Гц, 0: ФНЧ 20 кГц (практически выключен), +100: ФВЧ 5 кГц; без резонанса.
- **Fine.** У каждого потока есть расстройка в центах (−50…+50), на второй ручке Flow. Нужна для удвоения и хоруса (Thicken, Doubler, Wash): ручка Pitch идёт целыми полутонами.
- **Пресеты.** 12 заводских, генерирует `scripts/gen_presets.py`; тест рендерит каждый в `build_test/presets/`.
- **Нагрузка.** Три потока с Rate 5 мс на Pi 5: 4,6 % одного ядра. Запас большой, пул можно поднять, если понадобится.
- **Модуляция.** Два LFO на весь эффект (Sine, Tri, Drift — плавный случайный, S&H; 0,02–20 Гц) и сетка глубин
  LFO × поток × (Pitch, Offset, Length, Level), −100…+100 %. При 100: Pitch ±2 полутона, Offset и Length ×4 / 4,
  Level до тишины. Pitch меняет скорость чтения и у звучащих зёрен; чтобы зерно не догнало запись, отступ считается
  по наибольшей скорости, которую могут дать LFO. Настройка — на странице Mod виджета, новых ручек нет.
- **Length до 8 с**, но не длиннее Buffer: длинные зёрна для ровного пэда при Freeze и растянутых текстур.
  Внутренний буфер вырос до ~32 МБ (48 кГц); нагрузка на процессор не изменилась.
- **Spray, Feedback, интервалы, Sync, Env** (2026-11-13). Main: Stream, Mix, **Feedback**, Freeze (общий Gain убран:
  громкость задают Mix и Level потоков). Out: Reverse, Filter, **Spray**, Level; Spread находится на четвёртой ручке Flow.
  Spray — случайный момент (±0,9 Rate) и место (±Length) старта зерна. Интервалы — 9 наборов, нота на зерно случайно;
  высота зерна (Pitch + интервал) ограничена ±36 полутонами, высокое зерно укорачивается так, чтобы читать не больше
  8 с буфера. Feedback — выход зёрен (после фильтра и Level, до Mix) пишется обратно в буфер через DC-фильтр и мягкий
  ограничитель (линейно до 0,7, потолок 1), с задержкой в один блок (64 сэмпла). Sync — Rate и Offset встают на
  ближайшую из 20 длительностей при темпе хоста (time:Position), зёрна рождаются на сетке долей. Env — пик входа с
  падением 0,3 с, −48…−6 дБ → 0…1, третья строка сетки модуляции.
- **Название: Eka Grain Flow** (2026-11-13). Бандл `eka-grainflow.lv2`, URI `http://dmtry3.github.io/zynthian-eka/grainflow`,
  будущая папка `plugins/grainflow`. Снапшоты со старым Eka Grain не переносятся (другой URI).

- **Плавный Shape**: параметр `shape` Float 0…1. На нуле — Hann, на максимуме — окно с плоской серединой и долей скруглённых краёв 2 %; каждый край не короче 1 мс. Прежние значения Soft=0 и Sharp=1 загружаются, но верх диапазона теперь резче прежнего Sharp. Огибающая фиксируется при рождении зерна; нормализация учитывает её среднюю амплитуду. В аудиопотоке используется готовая таблица Hann, без тригонометрии и выделения памяти. В виджете — горизонтальный слайд и отдельная миниатюра окна над кнопкой.

- **Настраиваемый Env**: параметры `env_attack` (0…1000 мс, default 0), `env_release` (10…5000 мс, default 300), `env_sensitivity` (−24…+24 dB, default 0) добавлены в конец LV2 State без новых портов. Отдельный follower берёт максимум абсолютных значений входных каналов и сглаживает его Attack/Release до перевода −48…−6 dB в 0…1. Sensitivity прибавляется только при переводе в dB, аудиосигнал не усиливается. Панель открывается нажатием Env в матрице, возврат кнопкой LFO; регулировка вертикальная.

- **LFO Smooth**: `lfo1_smooth`, `lfo2_smooth` Float 0…100, default 0, добавлены в конец State. Однополюсное сглаживание исходного биполярного LFO перед преобразованием полярности, постоянная времени = 0,5 × Smooth² / текущая Hz (Smooth в 0…1). Ноль точно обходит сглаживание; состояние сбрасывается при gx_reset. UI: отдельные прямоугольники Smooth и →Rate под каждым графиком, горизонтальные жесты, двойное касание сбрасывает в 0.

- **LFO Sync**: `lfo1_sync`, `lfo2_sync` (Int 0/1, default 0), затем `lfo1_div`, `lfo2_div` (Int 0…19, default 12 = 1/4) добавлены в конец State. Частота = BPM / (60 × gx_div_beats[div]); модуляция Rate применяется после этого. Sync допускает до 128 Гц для точного 1/64 при 400 BPM; Free по-прежнему до 20 Гц. Фаза не сбрасывается при смене режима/темпа, не привязана к началу такта. Smooth использует текущий период. UI: кнопка Free/Sync в заголовке LFO, вертикальная настройка нот вместо Hz.

- **Матрица Filter/Scan**: два назначения добавлены в конец State отдельным блоком, прежние 36 ячеек и последующие параметры сохранили индексы. Глубины −100…+100 %. Filter — аддитивное смещение ±1 со сглаживанием 10 мс, ограниченное текущей стороной фильтра (ФНЧ/ФВЧ задаёт ручка). Scan — смещение скорости ±2, итог ограничен ±2; наличие маршрута включает курсор даже при Scan 0, пересечение нулевой скорости не сбрасывает позицию. UI — 6 столбцов без новых анимаций.
