# Отправка из WSL на Zynthian по SSH

GitHub и коммит не нужны: передаются текущие локальные файлы. Сборка и установка
выполняются на Pi штатными установщиками. После успешной установки интерфейс
Zynthian перезапускается один раз. Звук прервётся.

Из терминала WSL:

```bash
cd /home/demetry/projects/zynthian-eka
make deploy-tape
```

Выбор плагина: `make deploy-tape`, `make deploy-roll`, `make deploy-bloom`,
`make deploy-mist`, `make deploy-fold`. Только выбранный плагин передаётся,
собирается и устанавливается; остальные не пересобираются.

Весь набор:

```bash
make deploy
```

По умолчанию SSH: `root@zynthian.local`, папка на Pi: `/root/zynthian-eka`.
Другой адрес или каталог:

```bash
make deploy-fold DEPLOY_TARGET=root@192.168.1.50 DEPLOY_DIR=/root/eka-test
```

Прямой вызов без Make:

```bash
bash scripts/deploy-zynthian.sh fold root@192.168.1.50 /root/eka-test
bash scripts/deploy-zynthian.sh all
```

Нужны SSH-доступ под root, локальные bash/ssh/tar и зависимости сборки выбранного
плагина на Pi. SSH может запросить пароль дважды; при настроенном ключе пароль
не требуется. Первый ключ хоста подтверждайте после сверки с устройством.

Отправляются исходники выбранных плагинов, общий каталог common и корневой Makefile.
Заводские сэмплы и сторонний DSP-код включены. История Git, инструкции агентов,
локальные настройки, deploy.env и результаты сборок/тестов исключены.
Удалённые локально файлы автоматически с Pi не удаляются.

Каталог на Pi нельзя перемещать или удалять: LV2-бандлы и виджеты установлены
ссылками на него. Пользовательские данные в zynthian-my-data остаются на устройстве.
Если каталог является Git-копией, передача может изменить его рабочие файлы;
последующий git pull может потребовать разрешить эти изменения.

Старый scripts/deploy.sh внутри Tape теперь перенаправляет на этот SSH-деплой.
Его прежний deploy.env больше не используется; адрес задаётся аргументом.
