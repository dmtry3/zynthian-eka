# Проверка этапа 5 на Zynthian V5: скорость и следование темпу

Обновить на Pi:

```bash
cd zynthian-audio-looper && git pull && ./scripts/install.sh && systemctl restart zynthian
```

## Следование темпу (MODE = QUANTIZE)

1. Записать 2–3 дорожки при 120. Поменять темп в Zynthian на 140 (и обратно, и на ходу).
   Лупы плавно ускоряются за время TEMPO GLIDE (настройки, по умолчанию 500 мс), высота меняется
   как у ленты, щелчков и «плавания» нет.
2. Через пару секунд после смены лупы точно в долю с метрономом Zynthian (фазовая автоподстройка).
3. Внешний MIDI-клок как источник темпа в Zynthian: дрожание клока не слышно как вибрато.
4. Лупы, записанные в Free, темпу не следуют.

## Ручная скорость (экран Speed)

Касание по метке «1.00×» под номером дорожки на экране Loop открывает экран Speed этой дорожки.

1. Слайдер: 0,25× … 2× (две октавы вниз, одна вверх), отметки полутонов. Ход плавный (GLIDE).
   Скорость не 1× — метка у дорожки оранжевая.
2. SNAP: FREE / SEMI (полутоны) / OCT (0,25, 0,5, 1, 2). GLIDE: время плавного хода.
3. Пока скорость не 1×, дорожка расходится с сеткой, как лента.
4. Кнопка «1×» или двойной тап по крупному значению: скорость плавно к 1×, затем на ближайшем такте
   (по MUTE AT) дорожка встаёт в фазу через короткий кроссфейд.
5. Овердаб на скорости не 1×: после возврата к 1× слой звучит ниже/выше, как на ленте.
6. Reverse на скорости не 1× тоже разворачивается как лента.

## Педаль или ручка

Контроллер Speed на странице Mix: скорость активной дорожки, с захватом (catch), как Level.

## Приёмка этапа 5 (из ТЗ)

Смена темпа Zynthian со 120 на 140 не даёт щелчков и заметного вибрато, после установления темпа
ошибка позиции не больше 1 мс, после сброса скорости дорожка в фазе с тактом.

## Правки после первой проверки (2026-11-06)

1. Смена темпа: раньше скорость шла за фильтром темпа, а отставание по фазе догоняла отдельная
   подстройка +2 % почти секунду — высота «плыла» выше цели. Теперь скорость и фаза ведутся вместе:
   ошибка фазы при 120 → 140 не больше 7 мс (было 13), лупы встают в долю примерно за 1 с (было 2).
   Проверить: крутилкой темпа и скачком 120 → 140 → 120, на слух без «плавания».
2. Удержание Reset: микшер и скорость всех дорожек — по умолчанию (1×), курсор на первой дорожке
   первого парта.
3. Рамка активной дорожки — приглушённый зелёный.
4. Метроном: сильная доля белая, крупнее, с ореолом; слабые доли серые и мельче. На сильной доле фон полосы темпа ярко вспыхивает и гаснет за 0,2 с.
5. Режим канала в Mixer вместо SPLIT — кнопка по кругу ST → L → R. L: дорожка играет только левый
   вход как моно, панорама 0 — посередине, влево — слева, вправо — справа. R — то же для правого входа.
   Проверить: инструмент в L, запись, режим L — звучит по центру; R — тишина; ST — как записано.
6. TEMPO GLIDE: попробовать 1500–2000 мс и сказать, сливаются ли ступеньки при смене темпа по 1 BPM.
