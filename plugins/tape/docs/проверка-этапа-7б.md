# Проверка этапа 7б на Zynthian V5: касание на экране

Обновить на Pi (у плагина новые параметры `tsel`, `psel`, `wsel`, поэтому ставятся плагин и виджет вместе):

```bash
cd /root/zynthian-eka && git pull && sudo make install-tape && sudo systemctl restart zynthian
```

## 1. Дорожка касанием (Loop)

1. Коснитесь строки другой дорожки (по волне или пустому месту): она становится активной (зелёная, внизу `TRACK n`).
2. Касание метки скорости (`1.00×` под номером) по-прежнему открывает Speed, а не выбирает дорожку.
3. Во время записи основы в ROP коснитесь другой дорожки: цикл закрывается и играет без овердаба (как педаль).
4. Во время овердаба коснитесь другой дорожки: овердаб закрывается.

## 2. Парт касанием (Loop)

1. Запишите что-нибудь в парт 1, коснитесь точки парта 2 (левый столбик точек):
   точка мигает, внизу `PART 1 → 2`, переход на границе по PART AT.
2. Пока ждёт: коснитесь точки 3 — цель меняется на 3; коснитесь точки 3 ещё раз — переход отменён.
3. Пока ждёт: коснитесь точки текущего парта — переход отменён.
4. Из пустого парта касание точки переключает сразу.

## 3. Mixer

1. Коснитесь круга с номером над полосой дорожки: она становится активной (зелёная полоса).
2. Фейдеры, панорама, ST/L/R и M работают как раньше, случайно дорожка не меняется.

## 4. Кнопка экрана

1. На Loop слева от BPM кнопка `MIX`: открывает Mixer. На Mixer там же `LOOP`: возвращает на Loop.
2. Из настроек (шестерёнка) и из Speed кнопка тоже переключает экран и закрывает их.
3. Педали «Виджет Loop» и «Виджет Mixer» работают как раньше.
4. BPM и счёт `такт.доля` не наезжают на кнопку.

Номер пункта и что видно или слышно не так.
