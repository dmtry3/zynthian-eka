# Проверка этапа 4 на Zynthian V5: Mixer и режимы каналов

Обновить на Pi:

```bash
cd zynthian-audio-looper && git pull && ./scripts/install.sh && systemctl restart zynthian
```

Mixer открывается педалью 4 (контроллер «Mixer» на странице Screens), обратно — педаль 3.

## Экран Mixer (4 дорожки играющего парта, справа Dry и Master)

1. Фейдер дорожки тянется пальцем, уровень в дБ внизу. Двойной тап — 0 дБ. Вниз до упора — −∞.
   Громкость меняется плавно, без щелчков и «молнии».
2. Полоска панорамы: тянуть влево и вправо, двойной тап — центр.
3. ST / SPLIT — режим канала. M — mute этой дорожки (как педаль Mute, с fade и квантованием MUTE AT).
4. Индикаторы пика у каждой дорожки и у Master.
5. DRY — сухой сигнал, MASTER — сумма лупов. LIM — мягкий ограничитель мастера (по умолчанию включён):
   несколько громких дорожек не клиппят.

## Режимы каналов (тест-сигналом)

1. Подать сигнал только в L (например, гитара в левый вход), записать луп.
2. SPLIT, панорама в центре: звук только слева, справа тишина — L и R не смешиваются.
3. Панорама вправо: левый канал плавно переезжает направо, на краю — только справа.
4. ST, панорама: работает как баланс.

## Страница Mix (контроллеры Level, Pan, Master — под педаль экспрессии или ручку)

Шкала Level и Master как у фейдера: 75 = 0 дБ, 100 = +6 дБ, 0 = −∞; около 0 дБ ход очень точный.
Над ручкой Zynthian показывает положение 0..100, точное значение в дБ — на экране Mixer.

Захват (catch): после смены активной дорожки педаль ничего не меняет, пока не дойдёт до текущего
уровня этой дорожки; дальше ведёт плавно. Так же Pan и Master.

1. Уровень дорожки 1 педалью вниз. Следующая дорожка (её уровень 0 дБ): педаль не меняет громкость,
   пока не дойдёт до положения 0 дБ, потом ведёт.
2. Уровень, изменённый на экране Mixer, педаль тоже сначала «ловит».

## Сохранение и сброс

1. Сохранить снапшот, перезагрузить: уровни, панорамы, режимы, Dry, Master, LIM на месте.
2. Lock-дорожка в новом парте сохраняет уровень, панораму и режим.
3. Удержание Reset (1 с): всё очищается, микшер — в значения по умолчанию.

## Приёмка этапа 4 (из ТЗ)

В режиме Раздельно в центре L и R не смешиваются (проверка тест-сигналом), удержание Reset возвращает микшер в значения по умолчанию.
