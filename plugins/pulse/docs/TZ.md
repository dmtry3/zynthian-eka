# ТЗ: Eka Pulse — ритмический мультиэффект-шейпер для Zynthian

Версия 1.0 · 2026-11-20 · утверждённый концепт

**Eka Pulse** — ритмический мультиэффект-шейпер в формате LV2 для [Zynthian](https://zynthian.org) (Raspberry Pi 5, комплект V5, тачскрин 800×480), восьмой плагин бандла `zynthian-eka`.

- **Папка в монорепо:** `plugins/pulse/`
- **LV2 URI:** `http://dmtry3.github.io/zynthian-eka/pulse` (после первого коммита не менять)
- **Бандл / бинарник / виджет:** `eka-pulse.lv2` / `eka_pulse.so` / `zynthian_widget_eka_pulse.py`
- **Отображаемое имя (`doap:name`):** `Eka Pulse`
- **Лицензия:** GPL-3.0-or-later, чистый C11 + Python/Tkinter виджет, без внешних зависимостей.

---

## 1. Концепция и референсы

Идея: объединить музыкальную силу **Cableguys ShaperBox 3** (профильные модули-шейперы + Low Split кроссовер), **Devious Machines Infiltrator 2** (шаговый секвенсор + Envelope Follower + рандомизация) и **Polyverse Gatekeeper** (быстрый чоппер/гейт с `Smooth` и `Punch`) в одном живом инструменте, заточенном под **4 энкодера Zynthian** и **5-дюймовый тачскрин**.

Вместо мелкого векторного рисования кривых мышью используется **полиритмический Step Shaper** (до 16 шагов со своей длиной и формой каждого шага на каждый слот) плюс **единый экран живой игры `Perform`** с моментальными пэдами, XY-пэдом и сценами `A–D`.

Берём только идеи и общеизвестную DSP-технику. Код, графику, пресеты и названия референсных продуктов не используем.

## 2. Утверждённые решения

| Пункт | Решение |
|---|---|
| **Название** | **Eka Pulse** |
| **Архитектура слотов** | 4 фиксированных профильных шейпера: `1: TIME` → `2: DRIVE & CRUSH` → `3: FILTER` → `4: GATE & SPACE` + общий кроссовер **Low Split** |
| **Редактор кривой** | **Полиритмический Step Shaper** до 16 шагов, **своя длина (`1..16` шагов) у каждого слота** + выбор формы каждого шага (`Hold`, `Decay`, `Ramp`, `Pulse`, `2x`, `3x`) + 4 макро-ручки (`Pattern`, `Step Rate`, `Steps`, `Warp`) |
| **Модуль TIME** | **Оба режима на одном кольцевом буфере:** плавная **Time-Curve** (как TimeShaper: скретч, полускорость, плавный tape-stop) и дискретный **Step-Chopper** (как Infiltrator / Beat Repeat: `Thru`, `Repeat 1/8`, `Repeat 1/16`, `Half`, `Reverse`, `Stop` по шагам) |
| **Живая игра** | **Живые пэды (`Pads`) + XY-пэд + Сцены `A–D` на одном экране виджета** (вкладка `Perform` открывается со страницы энкодеров `Perform`; полоса сцен `A–D` видна прямо под пэдами) |

## 3. Звуковой тракт

```
 Audio In L/R ──┬──────────────────────────────────────────► Env / Transient Detector
                │                                            (Audio Trig + Env → Depth)
                ▼
      Low Split Crossover (Linkwitz-Riley 24 dB/oct, Off / 60..500 Hz)
        ├── Low Band (чистый или Low Duck от слота Gate) ───────────────────┐
        └── Main / High Band                                                │
               │                                                            │
               ▼                                                            │
        [1: TIME] ──► [2: DRIVE & CRUSH] ──► [3: FILTER] ──► [4: GATE & SPACE]
                                                                            │
                                                                            ▼
                                                           Dry/Wet Mix + Master Limiter ──► Out L/R
```

- **Нулевая задержка сухого сигнала:** сухой сигнал и обойдённая низкая полоса идут без задержки; при `Low Split = Off` кроссовер полностью обходится.
- **Независимый обход слотов:** каждый слот включается/выключается независимо с плавным кроссфейдом 5–10 мс без щелчков; выключенный слот не тратит CPU.
- **Мастер-лимитер:** стерео-линкованный brickwall-лимитер с нулевой задержкой на выходе (как в `Eka Weave-4`), индикатор `LIM` на виджете.

## 4. Полиритмический Step Shaper

У каждого из 4 слотов свой независимый генератор кривой:

1. **Длина петли `Steps` (`1..16`):**
   - Каждый слот имеет свою длину (например: `TIME` = 16, `DRIVE` = 5, `FILTER` = 7, `GATE` = 8).
   - В режиме `Sync` позиция считается детерминированно от транспорта Zynthian (`step_index = floor(beats / step_len) % slot_steps`), поэтому слоты не разъезжаются и сходятся в «1» при перезапуске транспорта.
2. **Данные шага (16 шагов × 4 слота):**
   - `Level` (`0..100%`) — высота столбика (рисуется свайпом пальца).
   - `Shape` (`0..5`) — форма сегмента внутри шага:
     - `0`: `_` **Hold** (ступенька)
     - `1`: `\` **Decay** (удар и спад)
     - `2`: `/` **Ramp** (нарастание)
     - `3`: `/\` **Pulse / Tri** (колокол/треугольник)
     - `4`: `2x` **Ratchet 2×** (два импульса за шаг)
     - `5`: `3x` **Ratchet 3×** (триоль за шаг)
3. **Быстрое управление 4 энкодерами:**
   - `Pattern` — 24 встроенных музыкальных паттерна (Sidechain, Trance Gate, Euclidean 3/8, 5/8, 7/16, Syncopated, Tape Stop End, Swell, Stutter Roll, Random) + `Custom`.
   - `Step Rate` — длительность **одного шага** (`1/32`, `1/16T`, `1/16`, `1/8T`, `1/8`, `1/4`, `1/2`, `1 bar`) или `Free Hz`.
   - `Steps` — длина цикла слота (`1..16`).
   - `Warp` — нелинейный изгиб форм шагов и смещение пика.
4. **Триггеры и модуляция входом (`Trigger`):**
   - `Trig`: `Sync` (транспорт), `Free` (внутренний клок), `Audio` (перезапуск с шага 1 при атаке входа выше `Threshold`), `MIDI` (перезапуск по Note On).
   - `Env → Depth` (`-100..+100%`): огибающая громкости входа модулирует глубину кривой слота.
   - `Smooth / Punch`: в плюс — сглаживание стыков (0.5–80 мс); в слоте `GATE` в минус — **Punch** (короткий буст/клиппер на фронтах открытия, как в Gatekeeper).

## 5. Детализация 4 слотов

### Слот 1: `TIME` (гибрид TimeShaper + Step-Chopper)
Стерео кольцевой буфер (~4 с при 48 кГц, ~1.5 МБ, выделяется в `instantiate()`, 4-точечная интерполяция Эрмита, кроссфейд 2–5 мс на скачках).
- **Режим `Curve` (TimeShaper):** кривая задаёт задержку чтения позади головки записи в пределах `Range` (`1/8`, `1/4`, `1/2`, `1 bar`). Наклоны кривой дают `Half-Speed`, `Tape-Stop`, `Reverse` и `Scratch`.
- **Режим `Chop` (Step-Chopper / Beat Repeat):** высота каждого шага выбирает действие:
  - `0%` = `THRU` (сквозной звук),
  - `1..25%` = `1/8` (повтор),
  - `26..50%` = `1/16` (дробь),
  - `51..75%` = `1/2x` (полускорость),
  - `76..90%` = `REV` (реверс),
  - `91..100%` = `STOP` (торможение ленты до нуля внутри шага).
- **Режимы `Stutter` и `TapeStop`:** специализированные быстрые режимы повторов и скорости мотора.

### Слот 2: `DRIVE & CRUSH`
- Режимы: `Tube` (мягкое асимметричное насыщение), `Fold` (вейвфолдер с ADAA), `Hard` (клиппер/фузз), `Crush` (Sample Rate + Bit Crush), `Combo` (Drive + Crush одновременно).
- Кривая модулирует интенсивность искажения; `Tone` / `Crush` задаёт яркость или глубину деградации.

### Слот 3: `FILTER`
- Режимы: `LP 24`, `LP 12`, `BP`, `HP`, `Morph` (`LP → BP → HP`), `Notch`, `Phaser` (4-ступенчатый allpass-фейзер с обратной связью).
- Топология TPT SVF (стабильна при быстрой шаговой модуляции). Кривая сдвигает `Cutoff` с учётом знака `Depth`.

### Слот 4: `GATE & SPACE`
- Режимы: `Gate` (быстрый амплитудный чоппер/сайдчейн с параметром `Floor`), `Pan` (ритмическая автопанорама), `Width` (M/S-расширение на акцентах), `Gate+Pan` (пинг-понг чоппер).
- Поддерживает `Punch` на фронтах и опцию `Low Duck` (применение огибающей Gate к нижней полосе Low Split).

## 6. Управление: 5 страниц по 4 энкодера

Страницы `FX`, `Curve` и `Trigger` управляют **выбранным слотом** (по образцу `Eka Grain Flow`: лицевые порты + `patch:writable` параметры слотов + синхронизация ручек виджетом при смене слота или загрузке пресета).

| Страница | Ручка 1 | Ручка 2 | Ручка 3 | Ручка 4 |
|---|---|---|---|---|
| **1. Main** | **Slot** (`1:Time`, `2:Drive`, `3:Filter`, `4:Gate`) | **Mix %** (общий Dry/Wet) | **Low Split** (`Off, 60..500 Hz`) | **Scene** (`A / B / C / D`) |
| **2. FX** *(слот)* | **Mode** (алгоритм слота) | **Param 1** *(Range / Drive / Cutoff / Floor)* | **Param 2** *(Win / Crush-Tone / Res / Width)* | **Depth** (`-100..+100%`) |
| **3. Curve** *(слот)* | **Pattern** (24 пресета + `Custom`) | **Step Rate** (`1/32 .. 1 bar`, `Free`) | **Steps** (`1..16`, полиритмия) | **Warp** (изгиб кривой) |
| **4. Trigger** *(слот)* | **Trig** (`Sync`, `Free`, `Audio`, `MIDI`) | **Threshold** (порог Audio Trig / Env) | **Env → Depth** (`-100..+100%`) | **Smooth / Punch** |
| **5. Perform** | **Live Pad** (`Off, TapeStop, Repeat 1/16, Repeat 1/8, Rev, Half, GateChop, FilterDrop, BitCrush`) | **Prev Scene** *(MIDI Learn педаль)* | **Next Scene** *(MIDI Learn педаль)* | **Output dB** (`-24..+6 dB` + Limiter) |

## 7. Виджет (`ui/zynthian_widget_eka_pulse.py`, 800×480)

Python/Tkinter, `MULTI_INSTANCE = True`, `UPDATE_PERIOD = 0.08` (не чаще ~12 Гц), кривые перерисовываются только при изменении параметров (`CURVE_PERIOD = 0.15`).

- **Левая колонка (всегда видна):** 4 цветные карточки слотов (`1 TIME` `#4dabf7`, `2 DRIVE` `#ffa94d`, `3 FILTER` `#63e6be`, `4 GATE` `#b197fc`). Показывают режим, длину петли (`7/16`) и мини-уровень кривой. Короткий тап выбирает слот; долгий тап (`0.6 с`) или повторный тап по выбранному — `ON / OFF`.
- **Верхние вкладки:** `Steps` | `Perform` | `Flow`.
  1. **`Steps`:** бегущий силуэт входного сигнала, `N` столбиков выбранного слота (`N = Steps`, свайп пальцем меняет высоту), гладкая кривая с учётом `Warp`/`Smooth`, плейхед выбранного слота и тонкие метки остальных слотов; строка форм шагов (`_`, `\`, `/`, `/\`, `2x`, `3x`, либо цветные метки действий `THRU / 1/8 / 1/16 / 1/2x / REV / STOP` для `TIME: Chop`); кнопки `Rnd`, `Shift < / >`, `Inv`.
  2. **`Perform` (живые пэды + XY + сцены A–D на одном экране):**
     ```
     ┌──────────┬──────────────────────────────────┬──────────────┐
     │ 1 TIME   │ [TapeStop] [1/16Rpt] [1/8Rpt]    │   XY PAD     │
     │ 2 DRIVE  │ [Reverse ] [Half1/2] [TranceGt]  │  X: Cutoff   │
     │ 3 FILTER │ [FiltDrop] [BitCrsh] [Bypass  ]  │  Y: Depth    │
     │ 4 GATE   ├──────────────────────────────────┴──────────────┤
     │ (On/Off) │ [ A ] [ B ] [ C ] [ D ]  [Store]  120 BPM [LIM] │
     └──────────┴─────────────────────────────────────────────────┘
     ```
     Пэды работают моментально (пока держишь палец; отпустил — возврат ровно в сетку). Внизу прямо под пэдами — полоса сцен `A | B | C | D` + `Store` (сохраняет/переключает все 4 слота и их полиритмические паттерны; также дублируется внизу на остальных вкладках).
  3. **`Flow`:** кривая кроссовера `Low Split` (перетаскивание частоты пальцем), тумблер `Low Duck`, индикатор уровня входа с линией порога `Audio Trig` и лампой срабатывания транзиента.

## 8. DSP-требования и производительность

- Частота дискретизации 44.1 / 48 кГц, блок 64–256 сэмплов.
- В `run()`: **0 аллокаций**, никаких блокировок, `printf` или I/O, включён flush-to-zero.
- Целевой бюджет CPU на Raspberry Pi 5: **≤ 8 % одного ядра** при всех 4 активных слотах и открытом виджете, 0 xruns.
- Движок (`src/pulse_fx.c/.h`) не зависит от LV2, чтобы тестировать его офлайн в WSL (`make test`, `SAN=1 make test`, рендер WAV в `build_test/`).
