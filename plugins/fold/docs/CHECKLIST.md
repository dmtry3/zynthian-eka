# Этап 1: Mod OSC, FM / AM / Sync, вкладка Mod

В WSL уже проверено тестами (`make test`, `SAN=1 scripts/test.sh`): боковые полосы FM и PM совпадают с теорией
(функции Бесселя, точность 0,5 дБ), кольцевая модуляция без несущей, Sync перезапускает Principal со сглаженным скачком,
Index и тумблеры меняются без щелчков, patch:Set / patch:Get и State в тестовом хосте, вкладка Mod на заглушках.

## 1. Установка

- [ ] `git pull`, в `plugins/fold`: `sudo make install`, `systemctl restart zynthian`.
- [ ] Страницы ручек по порядку: Osc, Mod, Env. На Mod: Mod Freq, Mod Index %, Mod Shape, Mod Mode.
- [ ] Mod Shape и Mod Mode показывают названия (Triangle / Sine / Saw / Square, Free / Keytrack / Ratio), а не числа.

## 2. Звук

- [ ] Mod Index 0: чистый синус, как на этапе 0.
- [ ] FM (по умолчанию включена), Ratio ×1, Index вверх: тембр становится ярче, высота ноты та же.
- [ ] Ratio ×3/2, ×7/2: металлические, колокольные тембры; ×1/2: появляется октава вниз.
- [ ] AM: на Index 100 % кольцевая модуляция (основной тон пропадает).
- [ ] Sync с Ratio ×3/4 и ×5/4: высота ноты идёт от Mod OSC, тембр «рвёт» без треска. (×1/2 и ×2/3 ничего не меняют: сброс приходится на ноль синуса.)
- [ ] Free 1–5 Hz с FM: вибрато (через ноль при большом Index), с AM: тремоло. Новая нота не сбрасывает LFO.
- [ ] Резко крутить Index и переключать FM / AM / Sync во время ноты: без щелчков.
- [ ] Высокие ноты (C6–C7) с Saw или Square и большим Index: слышен ли алиасинг (металлический призвук, не по нотам)?

## 3. Виджет, вкладка Mod

- [ ] Вкладки Osc и Mod; поворот на страницу Mod открывает вкладку Mod, тап по вкладке выбирает страницу.
- [ ] Тап по стрелке FM / AM / Sync включает и выключает маршрут, звук меняется сразу.
- [ ] Блок Principal меняет форму при повороте Index, Shape, Mod Freq и переключении маршрутов.
- [ ] Внизу: Index крупно и смысл Mod Freq («Ratio ×3/2 · Saw», «Free 0.63 Hz», «Keytrack +7.0 st»).
- [ ] Free до 8 Hz: точка бежит по форме Mod OSC.
- [ ] Снапшот с включёнными AM и Sync: сохранить, перезапустить Zynthian, загрузить. Тумблеры на месте?
- [ ] Шрифты и стрелки читаются и нажимаются пальцем на экране V5.

# Этап 0

Что проверить на Pi 5, чтобы закрыть M0. В WSL уже проверено тестами (`make test`, `SAN=1 scripts/test.sh`):
частота нот (44.1 и 48 кГц), Pitch, Fine, pitch bend, огибающая, освобождение голосов, перехват 5-й ноты без щелчка,
педаль sustain, All Notes Off / All Sound Off, MIDI с точностью до сэмпла, нет NaN; виджет на заглушках Zynthian.
Здесь только то, что зависит от Zynthian, jalv и железа.

## 1. Сборка и установка

- [ ] `git pull`, затем в `plugins/fold`: `sudo make install`. Сборка без ошибок и предупреждений (gcc на aarch64, `-mcpu=cortex-a76`).
- [ ] `systemctl restart zynthian`. В списке инструментов есть «Eka Fold», в логе нет ошибок про eka-fold.
- [ ] Страницы ручек Osc (Pitch, Fine cents) и Env (Attack ms, Decay ms, Sustain %, Release ms).

## 2. Звук

- [ ] Нота с клавиатуры звучит, A4 = 440 Гц (тюнер или на слух против другого синта).
- [ ] Аккорд из 4 нот: все звучат, без перегруза.
- [ ] 5-я и 6-я ноты поверх 4 зажатых: старые ноты уходят без щелчка.
- [ ] Повтор той же ноты при длинном Release: без щелчка, голос один.
- [ ] Педаль sustain держит ноты, отпускание отпускает.
- [ ] Pitch bend ±2 полутона. Поворот Pitch и Fine во время ноты: высота меняется без щелчков.
- [ ] Крутить Sustain во время зажатой ноты: громкость меняется плавно.
- [ ] Panic (All Notes Off) глушит всё.

## 3. Виджет

- [ ] Виджет открывается: вкладка Osc, справа вверху имя страницы, плитка Sine, 2 периода синуса, индикатор уровня справа.
- [ ] Ноты и частоты внизу появляются при игре и пропадают после release.
- [ ] Поворот на страницу Env: вкладка остаётся Osc, имя страницы меняется на Env. Тап по вкладке Osc возвращает страницу Osc.
- [ ] Размеры и шрифты читаются на 5-дюймовом экране V5.
- [ ] Два экземпляра плагина в двух цепочках: у каждого свой виджет.
