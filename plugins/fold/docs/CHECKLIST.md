# Этап 3: Lopass Gate (вактрол), FG1 / FG2, вкладки Gate и Env

В WSL уже проверено тестами: времена FG и режимы Once / Gate / Cycle, ретриггер с текущего уровня; вактрол открывается
за 2–3 мс, закрывается по Decay и к тишине медленнее (второй участок −20 дБ в 1,34 раза дольше первого); LP и Combo
темнеют при затухании на 23 дБ (h7/h1), VCA нет; Resonance поднимает гармоники у среза на 28 дБ; смена режима без
щелчков; FG2 -> Timbre; мягкий клип держит выход ниже 1; вкладки Gate и Env на заглушках.

## 3. Виджет
