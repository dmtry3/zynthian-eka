# Проверка на устройстве (этап 0)

Что проверить на Pi 5, чтобы закрыть M0. В WSL уже проверено тестами (`make test`, `SAN=1 scripts/test.sh`):
частота нот (44.1 и 48 кГц), Pitch, Fine, pitch bend, огибающая, освобождение голосов, перехват 5-й ноты без щелчка,
педаль sustain, All Notes Off / All Sound Off, MIDI с точностью до сэмпла, нет NaN; виджет на заглушках Zynthian.
Здесь только то, что зависит от Zynthian, jalv и железа.

Отмечайте `[x]`, а проблемы записывайте под пунктом. Логи: `journalctl -u zynthian -f`.

## 1. Сборка и установка

- [ ] `git pull`, затем в `plugins/fold`: `sudo make install`. Сборка без ошибок и предупреждений (gcc на aarch64, `-mcpu=cortex-a76`).
- [ ] `systemctl restart zynthian`. В списке инструментов есть «Eka Fold», в логе нет ошибок про eka-fold.
- [ ] Две страницы ручек: Osc (Pitch, Fine cents) и Env (Attack ms, Decay ms, Sustain %, Release ms), в этом порядке.

## 2. Звук

- [ ] Нота с клавиатуры звучит, A4 = 440 Гц (тюнер или на слух против другого синта).
- [ ] Аккорд из 4 нот: все звучат, без перегруза.
- [ ] 5-я и 6-я ноты поверх 4 зажатых: старые ноты уходят без щелчка.
- [ ] Повтор той же ноты при длинном Release: без щелчка, голос один.
- [ ] Педаль sustain держит ноты, отпускание отпускает.
- [ ] Pitch bend ±2 полутона. Поворот Pitch и Fine во время ноты: высота меняется без щелчков.
- [ ] Крутить Sustain во время зажатой ноты: громкость меняется плавно.
- [ ] Panic (All Notes Off) глушит всё.

## 3. Виджет

- [ ] Виджет открывается: вкладка Osc, справа вверху имя страницы, плитка Sine, 2 периода синуса, индикатор уровня справа.
- [ ] Ноты и частоты внизу появляются при игре и пропадают после release.
- [ ] Поворот на страницу Env: вкладка остаётся Osc, имя страницы меняется на Env. Тап по вкладке Osc возвращает страницу Osc.
- [ ] Размеры и шрифты читаются на 5-дюймовом экране V5.
- [ ] Два экземпляра плагина в двух цепочках: у каждого свой виджет.
