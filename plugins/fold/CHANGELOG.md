# Changelog

## 0.7 (2026-11-12)

First version (LV2 version 0.7: lv2:minorVersion 0, lv2:microVersion 7).

- LV2 instrument, up to 8 voices (Voices 1..8), Poly / Mono / Legato, Glide, pitch bend range; sustain pedal,
  All Notes Off / All Sound Off, a stolen voice fades out in 2 ms.
- Principal oscillator: Sine, VA, FM2, Wave, with Harmonics, Color, Morph; a crossfade when the source changes.
- Mod OSC (triangle, sine, saw, square; Free, Keytrack, Ratio) into the Principal through linear through-zero FM,
  AM, band-limited hard Sync and Timbre, one Mod Index.
- Timbre section: wavefolder (ADAA), Saw and M Chebyshev shapers blended by Order, Symmetry, Drive; voices at 2x
  with a halfband decimator.
- Lopass gate on a vactrol model: VCA, LP, Combo; Decay, Resonance (self-limiting), Level.
- Function generators FG1 (the gate) and FG2: Rise, Fall, Once / Gate / Cycle.
- Mod matrix 8 x 11 (FG1, FG2, Mod OSC, Random, Velocity, Key, Mod wheel, Aftertouch -> Pitch, Harmonics, Color,
  Morph, Mod Index, Order, Symmetry, Timbre, LPG, Delay Time, Delay Feedback), every 32 samples, empty cells skipped.
- Waveguide / delay in every voice: Tuned (a string -24..+24 semitones from the note, in tune within a cent) or Free
  (1 ms .. 2 s), peaking EQ and shaper in the loop, the tail keeps the voice alive.
- Touch widget with eight tabs: Osc, Mod, Fold, Gate, Env, Delay, Play, Matrix.
- 25 factory presets (bank Factory), generated by `scripts/gen_presets.py` and played by the tests.
- Raspberry Pi 5: 8 voices in the heaviest patch 18 % of one core (bench), jalv 11 % in Zynthian, no xruns.
