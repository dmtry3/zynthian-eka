# Eka Q-4 для Zynthian

[English](README.md) · **Русский**

**Четырёхполосный параметрический эквалайзер** для [Zynthian](https://zynthian.org): аудио-эффект в формате **LV2** (стерео вход, стерео выход) с **интерактивным тач-виджетом** (перетаскиваемые точки на графике АЧХ, ручки HPF/LPF, живой 24-полосный анализатор спектра, свайп-ползунок Q, прослушивание Solo и индикаторы IN/OUT).

Сделан под четыре энкодера: шесть логичных страниц управления — по одной на каждую полосу, срезы/Tilt и мастер-секция.

> Проверено на: Zynthian **Vangelis** (stable 2610), Raspberry Pi 5, набор V5, тачскрин 800×480.
> Другие версии и железо не проверялись.

## Возможности

- **4 параметрические полосы (64-битные биквадратные фильтры TDF-II):**
  - **Band 1 (низ, `20..1000 Гц`):** `Shelf`, `Bell`, `Pultec` (подъём низа с мягким компенсационным подрезом верхней части баса), `Off`.
  - **Band 2 (нижняя середина, `60..4000 Гц`):** `Bell`, `Notch` (узкий вырез резонансов и обратной связи), `Off`.
  - **Band 3 (верхняя середина, `250..12000 Гц`):** `Bell`, `Notch`, `Off`.
  - **Band 4 (верх, `800..20000 Гц`):** `Shelf`, `Bell`, `Air` (широкий мягкий шельф «воздуха»), `Off`.
- **Края и Tilt:** обрезные фильтры Баттерворта `HPF` (`20..600 Гц`, на `20 Гц` выключен), `LPF` (`2..20 кГц`, на `20 кГц` выключен) с крутизной `12` или `24 дБ/окт`, плюс симметричные качели `Tilt` (`-6..+6 дБ` вокруг `1 кГц`).
- **Концертные инструменты:** глобальный масштаб кривой `Scale` (`0..200%`), плавное прослушивание полосы `Solo` (`Off / Band 1..4`), автокомпенсация громкости `AutoGain` и выходной уровень `Output` (`-18..+18 дБ`).
- **24-полосный анализатор спектра в реальном времени:** без задержки, рисуется мягким силуэтом под кривой АЧХ.
- **10 заводских пресетов** (банк *Factory*): `Init`, `Vocal Clarity & Air`, `Acoustic Guitar Polish`, `Bass Pultec Weight`, `Warm Keys & Rhodes`, `Tape Loop Mud Clean`, `Granular Cloud Sculpt`, `West Coast Fold Tame`, `Stage Anti-Feedback`, `Master Smile & Air`.
- **Безопасен для реального времени:** без выделений памяти в `run()`, защита от денормалов и NaN, плавное сглаживание коэффициентов без щелчков.

## Установка

На Zynthian (SSH под root):

```bash
git clone https://github.com/dmtry3/zynthian-eka.git
cd zynthian-eka/plugins/q4
sudo make install
systemctl restart zynthian
```

Обновление одной строкой:

```bash
cd /root/zynthian-eka && git pull && sudo make install-q4 && systemctl restart zynthian
```

| Ссылка или папка | Что внутри |
|---|---|
| `/usr/local/lib/lv2/eka-q4.lv2` | LV2-бандл (`eka_q4.so`, `manifest.ttl`, `eka_q4.ttl`, `presets.ttl`) |
| `zyngui/widgets_user/zynthian_widget_eka_q-4.py` | Тач-виджет (`ui/zynthian_widget_eka_q4.py`) |
| `zynthian-my-data/presets/lv2/Eka_Q-4.presets.lv2` | Папка пользовательских пресетов |

`install.sh` также обновляет кэш пресетов Zynthian. Файлы самого Zynthian не изменяются. Удаление: `sudo make uninstall`.

При первом добавлении включите **Eka Q-4** в webconf Zynthian (*Software → LV2 Plugins*), затем добавьте его в цепочку как *Audio Effect*.

## Управление

Шесть страниц по 4 энкодера:

| Страница | Ручка 1 | Ручка 2 | Ручка 3 | Ручка 4 |
|---|---|---|---|---|
| **1. Band 1** | `B1 Freq` (`20..1000 Гц`) | `B1 Gain` (`-18..+18 дБ`) | `B1 Q` (`0.2..12`) | `B1 Type` (`Shelf/Bell/Pultec/Off`) |
| **2. Band 2** | `B2 Freq` (`60..4000 Гц`) | `B2 Gain` (`-18..+18 дБ`) | `B2 Q` (`0.2..16`) | `B2 Type` (`Bell/Notch/Off`) |
| **3. Band 3** | `B3 Freq` (`250..12000 Гц`) | `B3 Gain` (`-18..+18 дБ`) | `B3 Q` (`0.2..16`) | `B3 Type` (`Bell/Notch/Off`) |
| **4. Band 4** | `B4 Freq` (`800..20000 Гц`) | `B4 Gain` (`-18..+18 дБ`) | `B4 Q` (`0.2..12`) | `B4 Type` (`Shelf/Bell/Air/Off`) |
| **5. Cuts & Tilt** | `HPF` (`20..600 Гц`) | `LPF` (`2..20 кГц`) | `Tilt` (`-6..+6 дБ`) | `Slope` (`12 / 24 дБ`) |
| **6. Master** | `Scale` (`0..200%`) | `Solo` (`Off / B1..B4`) | `AutoGain` (`Off / On`) | `Output` (`-18..+18 дБ`) |

## Виджет и жесты

- **График АЧХ:** тяните точки `1..4` влево/вправо (`Freq`) и вверх/вниз (`Gain`); маркеры `H` и `L` на линии `0 дБ` задают `HPF` и `LPF`.
- **Двойной тап** по точке сбрасывает её `Gain` в `0 дБ` (для `H`/`L` — выключает срез).
- **Полоска Q:** проведите влево/вправо, чтобы изменить ширину `Q` выбранной полосы прямо с экрана.
- **Нижние кнопки:** тап по `B1..B4` выбирает полосу (**долгий тап** выключает/включает её); кнопка типа переключает режим фильтра; `SOLO` прослушивает выбранную полосу; `AUTO` включает `AutoGain` (**долгий тап** включает общий `Bypass` — весь виджет становится серым).
