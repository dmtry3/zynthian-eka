# Отправка из WSL на Zynthian

GitHub не нужен: скрипт передаёт текущее содержимое проекта по SSH, включая
несохранённые в Git изменения. Сборка выполняется на Zynthian существующим
`scripts/install.sh`, затем перезапускается интерфейс. Звук прервётся.

1. В терминале WSL перейдите в проект:

   ```bash
   cd /home/demetry/projects/zynthian-eka-grain-flow
   ```

2. Запустите отправку и установку:

   ```bash
   bash scripts/deploy-zynthian.sh
   ```

   При первом подключении SSH попросит подтвердить ключ устройства, затем
   введите пароль root от Zynthian. Пароль может потребоваться дважды:
   при передаче файлов и при установке. Если SSH-ключ уже настроен,
   пароль не потребуется.

Если имя `zynthian.local` не находится, укажите IP устройства, например:

```bash
bash scripts/deploy-zynthian.sh root@192.168.1.50
```

По умолчанию файлы попадут в `/root/zynthian-eka-grain-flow`. Можно указать
другую папку вторым аргументом:

```bash
bash scripts/deploy-zynthian.sh root@192.168.1.50 /root/eka-grainflow-test
```

Повторный запуск обновляет файлы и переустанавливает плагин. Папку на
Zynthian не удаляйте и не перемещайте: установщик создаёт ссылки на неё.
Удалённые локально файлы на устройстве автоматически не удаляются.
История Git, локальные настройки, `.env`, результаты сборки и тестовые WAV
не отправляются. Нужны рабочий SSH-доступ под root и зависимости сборки на
Zynthian (`gcc`, `pkg-config`, `python3`, `lv2-dev`).
