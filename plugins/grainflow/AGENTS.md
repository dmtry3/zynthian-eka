# Eka Grain Flow

Гранулярный LV2-эффект для живой игры на Zynthian (Raspberry Pi 5), шестой
плагин бандла `zynthian-eka`. Правила перенесены из `CLAUDE.md`;
описание возможностей — `README.ru.md`, ТЗ — `docs/TZ.md`, проверки на
устройстве — `docs/CHECKLIST.md`.

## Правила работы

- Плагин находится в `zynthian-eka/plugins/grainflow/`. Прежний приватный репозиторий остаётся архивом разработки.
- Сохранять структуру соседних плагинов Mist и Fold: `src/`, `lv2/`, `ui/`, `scripts/`, `test/`, `docs/`, Makefile-обёртка.
- Общие правила монорепозитория задаёт корневой AGENTS.md. LV2 URI и имена бандла, бинарника и виджета не менять.
- Коммитить и пушить в `main` можно без дополнительных вопросов.
- Язык C, чистый LV2, без новых зависимостей. В аудиопотоке запрещены
  выделение памяти и блокировки.
- `lv2/*.ttl` генерирует `scripts/gen_ttl.py`, который вызывает и
  `scripts/build.sh`. Менять генератор, а не сгенерированные TTL.
  Порядок портов и параметров в генераторе и `src/eka_grainflow.c`
  должен совпадать.
- Команды для пользователя писать целиком и по шагам: пользователь
  начинающий в инструментах работы с кодом.

## Сборка и проверки

- Linux / WSL: `make` (нужен `lv2-dev`), затем `make test` и
  `SAN=1 make test`.
- Без установленных заголовков:
  `LV2_CFLAGS=-I/путь/к/lv2/include make test`.
- Тесты сохраняют WAV-файлы для прослушивания в `build_test/`.
- На Zynthian: `sudo make install`, затем
  `systemctl restart zynthian`. Проверки на устройстве описаны в
  `docs/CHECKLIST.md`.

## Устройство проекта

- `src/grain_fx.c` — движок без LV2: кольцевой буфер, три потока,
  пул зёрен, Freeze, фильтр и микс.
- `src/eka_grainflow.c` — LV2-обёртка. Main управляет общими
  параметрами; Grain, Flow и Out — выбранным потоком. Актуальные ручки Main:
  Stream, Mix, Feedback, Freeze; Grain: Offset, Rate, Length, Pitch;
  Flow: Scan, Fine, Intervals, Spread; Out: Reverse, Filter, Spray, Level. Эти названия учитывают обновления
  из `README.ru.md` и заметок реализации в `docs/TZ.md`.
- Значения потоков хранятся в плагине как LV2-параметры
  `s1_offset` … `s3_level`, `sN_on`; общие параметры включают `buffer`
  и `shape`. Поворот ручки Grain/Flow/Out записывает значение в выбранный
  поток и сообщает его хосту через `patch:Set`.
- При смене потока виджет переставляет ручки всех трёх страниц на значения этого потока:
  плагин не может сам менять свои входные порты.
- `ui/zynthian_widget_eka_grain_flow.py` — виджет буфера, зёрен,
  вертикальных кнопок потоков слева и Freeze.
- Pitch потоков: +12, 0, −12. Factory Init включает только поток 2; новый экземпляр без загрузки пресета — поток 1.
- Intervals 0…8 — прежние случайные наборы, 9…13 — Q Oct / Q Fifth / Q Major /
  Q Minor / Q Penta. В Q-режимах Pitch с модуляцией фиксируется при рождении зерна;
  Fine добавляется после округления.
