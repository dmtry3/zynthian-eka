# Eka Roll для Zynthian

[English version](README.md)
Demo video https://www.youtube.com/watch?v=ChqsykTJQ88

MIDI-лупер для [Zynthian](https://zynthian.org): **LV2-плагин (MIDI-инструмент)** внутри цепочки и необязательный
**виджет на сенсорном экране** (piano roll, слои, слоты).

Записывает и дозаписывает ноты и движения ручек, держится в такт с транспортом Zynthian (`zynseq`), умеет экспортировать
луп в MIDI-файл и сразу в паттерн `zynseq`.

> Проверено на: Zynthian **Vangelis** (stable 2610), Raspberry Pi 5, комплект V5, экран 800x480.
> Другие версии и железо не проверялись.

## Возможности

- **Привязка к транспорту.** Луп идёт только пока играет транспорт Zynthian (`zynseq`) и следует за темпом.
  Запись начинается и заканчивается на границе доли, такта или круга (*Launch*), поэтому первая доля всегда совпадает.
- **Rec / Overdub / Play / Stop**, до **8 слоёв**, mute, удаление слоя, undo/redo.
- **Свободная или фиксированная длина** (Free, 1, 2, 4, 8, 16 тактов), по фиксированной запись останавливается сама.
- **Умный тайминг.** Ноты, сыгранные чуть раньше первой доли в режиме ARM, записываются с начала такта. Ноты, нажатые
  перед концом лупа в овердабе, пишутся в начало лупа (без «микронот»).
- **Контроллеры на общей дорожке.** CC, pitch bend и aftertouch хранятся на одной дорожке (не по слоям). Касание
  ручки глушит её воспроизведение и перезаписывает старые значения, пока вы её двигаете. Через 0,5 с покоя
  воспроизведение возвращается.
- **Квантизация** (1/4 ... 1/32, сила, начала/концы/оба) для слоёв, выбранных на экране. Можно отменить.
- **Правка.** Half / Double, **транспонирование каждого слоя отдельно**.
- **16 слотов** на диске, автозагрузка сохранённого слота при восстановлении снапшота Zynthian.
- **Экспорт** одной кнопкой в `.mid` и в паттерн `zynseq` (4 шага на долю).
- **Виджет.** Состояние, прогресс, доли и слои; piano roll с тактами, нотами и дорожкой CC (страница Edit);
  выбор слоёв (Quantize); карта слотов (Slots).
- Игра с клавиатуры всегда проходит насквозь, лупер её не блокирует.

## Требования

- Zynthian с работающим `zynseq` как мастером транспорта и темпа.
- `gcc`, `pkg-config`, заголовки LV2 (`lv2-dev` или собранные из исходников).
- В MIDI-настройках цепочки должен быть включён **Route CC**, иначе Zynthian не передаёт CC в цепочку.

## Установка

```bash
git clone https://github.com/dmtry3/zynthian-eka.git
cd zynthian-eka/plugins/roll
sudo ./scripts/install.sh      # собирает плагин и создаёт две ссылки (см. ниже)
sudo systemctl restart zynthian
```

Скрипт создаёт:

| Ссылка | Куда ведёт |
|---|---|
| `/usr/local/lib/lv2/eka-roll.lv2` | `build/eka-roll.lv2` |
| `/zynthian/zynthian-ui/zyngui/widgets_user/zynthian_widget_eka_roll.py` | `ui/zynthian_widget_eka_roll.py` |

Файлы самого Zynthian не изменяются. Удалить: `sudo ./scripts/uninstall.sh`.

Добавьте **Eka Roll** в цепочку как *MIDI-инструмент* перед синтом.

## Управление

Контроллеры сгруппированы в страницы по 4 (по числу зинпотов). Все кнопки переключательные: любое изменение значения
считается нажатием.

| Страница | Контроллер | Что делает |
|---|---|---|
| **Loop** | Rec/Dub | Пусто: взвести запись. Запись: взвести остановку. Играет: овердаб вкл/выкл |
| | Play/Stop | Заглушить / включить луп (позиция продолжает идти) |
| | Undo/Redo | Повернуть крутилку и сразу вернуть (или тап / нажатие): отмена последнего действия (слой овердаба, Quantize, Half, Double, Transpose), на несколько шагов назад. Повернуть и подержать 0,5 с (или долгое касание / нажатие): вернуть отменённое по порядку; крутилка вернётся сама. Новый овердаб или правка забывают то, что можно было вернуть; Clear, удаление слоя и загрузка слота очищают историю. Каждый Undo/Redo пишет внизу экрана, что сделано |
| | Clear | Стереть всё (нажать дважды) |
| **Layers** | Layer | Выбор слоя для Mute / Delete |
| | L Mute | Mute выбранного слоя |
| | L Delete | Удалить выбранный слой (дважды) |
| **Timing** | Length | Free, 1, 2, 4, 8, 16 тактов |
| | Launch | Beat / Bar / Loop: когда начинается запись и воспроизведение |
| | Half / Double | Укоротить / удлинить луп вдвое (включая дорожку CC) |
| **Quantize** | Grid | Off, 1/4, 1/8, 1/16, 1/32 |
| | Strength | 0-100 % |
| | Target | Starts / Ends / Both |
| | Apply | Квантовать слои, выбранные на виджете |
| **Edit** | Layer | Слой для транспонирования |
| | Transpose | Полутонов добавить (-12...+12) |
| | Apply | Добавляет Transpose к сдвигу слоя, ручка возвращается в 0 |
| | Export | `.mid` + паттерн `zynseq` |
| **Slots** | Slot | 1-16 (0 = не выбран) |
| | Save / Load | Сохранить в слот / загрузить (загрузка в конце круга) |
| | Del Slot | Удалить файл слота (дважды) |

Повторный Undo/Redo в течение 0,3 с игнорируется (сенсорный экран иногда засчитывает один тап дважды).

Секвенсор Zynthian может остановить или перезапустить сцену, пока транспорт JACK продолжает идти. Виджет передаёт
лупу текущую долю zynseq (через общую память, вместе с выбором слоёв для Quantize): луп встаёт, когда zynseq остановлен, а сильная доля совпадает с
zynseq при запуске сцены.

Half, Double, оба Apply и Export срабатывают только на нажатии (отпускание момент-педали игнорируется), поэтому их
можно привязывать к кнопкам железа.

### Виджет

- На всех страницах: состояние (EMPTY, ARM REC, REC, OVERDUB, PLAY, STOP, ...), такты и BPM, прогресс лупа, доли,
  слои (у каждого слоя свой цвет), сообщения и подтверждения.
- На всех страницах, кроме Slots: piano roll с тактами и долями, слои в цвете, дорожка CC снизу; сверху доли и
  полоска слоёв (тап выбирает слой).
- **Quantize:** полоска слоёв выбирает, какие слои квантовать (тап включает/выключает); выбранная сетка рисуется
  голубым поверх нот (ярче сразу после смены).
- **Edit:** белый контур предпросмотра транспонирования.
- **Slots:** карта занятых слотов (16 клеток).

## Экспорт

- `.mid`: `/zynthian/zynthian-my-data/capture/eka_roll_ГГГГММДД_ЧЧММСС.mid` (слои без mute, с применённым
  транспонированием, темп и размер в файле).
- Паттерн: если ячейка секвенсора цепочки (текущая фраза x MIDI-канал цепочки) играет, её паттерн перезаписывается.
  Иначе заполняется первый пустой паттерн и назначается в эту ячейку, если она свободна. 4 шага на долю, точное
  время нот сохраняется смещением внутри шага (`EXPORT_USE_OFFSET` в виджете), движения CC превращаются в плавные
  отрезки. Константы в начале `ui/zynthian_widget_eka_roll.py`.

## Ограничения

- Нужен запущенный транспорт. Остановка или перемотка транспорта и смена темпа во время **первой** записи отменяют
  эту запись.
- Воспроизводимые CC также управляют привязками MIDI-learn Zynthian (параметры синтов и эффектов, ручки на экране). Это делает виджет, поэтому работает после первого открытия страницы Eka Roll с момента загрузки. Фильтр эха защищает от обратной связи.
- Ёмкость: 8 слоёв x 4000 событий, 16384 событий контроллеров.
- Снапшот хранит только значения контроллеров. Данные лупа лежат в слотах (сохранённый слот подгружается при
  восстановлении снапшота).
- Время лупа привязано к позиции транспорта в момент записи.

## Если что-то не работает

| Проблема | Что проверить |
|---|---|
| Плагина нет в списке | `lv2ls \| grep zynthian-eka/roll`, перезапуск Zynthian |
| CC не записываются | Включить *Route CC* в цепочке; проверить `jack_midi_dump` на выходе роутера цепочки |
| Нет виджета | Есть ли ссылка в `widgets_user`; `journalctl -u zynthian \| grep -i widget` |
| Пустой piano roll | `ls /dev/shm \| grep eka_roll` |
| Луп не играет | Транспорт должен идти (нажмите Play в zynseq) |

## Как устроено

- `src/eka_roll.c`: весь движок. Время в тиках (960 на долю), привязано к JACK-транспорту через `time:Position`.
  Воспроизведение сэмпл-точное внутри каждого аудиоблока.
- Файлы слотов пишет и читает рабочий поток (никогда аудиопоток).
- Виджет читает луп из общей памяти (`/dev/shm/eka_roll_<pid>`), а состояние из выходных портов плагина
  («мониторы» Zynthian). Записывает он только через обычные контроллеры.
